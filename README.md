# Автоматическое обновление товаров для Яндекс KIT

Скрипт строит полный YML-фид по свежей выгрузке товаров из KIT и YML поставщика.

## Что обновляется

| Данные поставщика | Поле в KIT |
|---|---|
| Остаток `Москва` | `Основной склад` |
| Остаток `Владивосток` | `Владивосток` |
| Параметры товара | Характеристики по артикулу |
| Фотографии | Холст 1200×1200, без обрезки, белый фон |
| Описание | Без артикулов, штрихкодов, URL и имён файлов |
| Вес | Фактический вес; если отсутствует или равен нулю — 3000 г |

`Склад №1нино` в фид не передаётся. Цены и названия берутся из выгрузки KIT и не меняются. Товары, которых уже нет в YML поставщика, остаются в фиде с `available="true"`, но с нулевыми остатками Москвы и Владивостока.

## Ручной запуск

```bash
python3 build_kit_feed.py --kit products.xlsx --output kit_feed.yml --report kit_feed_report.csv
```

Перед подключением автоматического обновления загрузите `kit_feed.yml` в KIT вручную и проверьте на нескольких товарах:

1. Остаток «Основного склада» равен Москве.
2. Остаток Владивостока обновился.
3. Остаток «Склад №1нино» не изменился.
4. Карточка без остатка осталась опубликованной.
5. Фото вписано в квадрат и не обрезано.

После проверки файл можно публиковать по постоянной HTTPS-ссылке и указать её как источник YML в KIT.

В комплекте есть GitHub Actions (`.github/workflows/update-kit-feed.yml`): он пересобирает фид ежедневно в 02:20 UTC и сохраняет результат в репозиторий. При добавлении новых товаров в KIT замените `products.xlsx` свежей полной выгрузкой — существующие остатки склада «Склад №1нино» в этом файле скрипт не использует и не передаёт.

## Важно

Для квадратных фотографий применён сервис `wsrv.nl`: KIT получает готовое изображение 1200×1200 по URL и сохраняет его. Если не хотите зависеть от внешнего сервиса, изображения можно заранее обработать и разместить на собственном домене — логика остального фида останется прежней.
